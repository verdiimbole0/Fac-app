# Modèles réutilisables (annexes A à J)

Chaque modèle de l'ouvrage existe en deux versions modifiables :

| Annexe | Classeur Excel | Document Word |
|---|---|---|
| A | Annexe_A_Fiche_d_inventaire_des_archives.xlsx | Annexe_A_Fiche_d_inventaire_des_archives.docx |
| B | Annexe_B_Modele_de_plan_de_classement.xlsx | Annexe_B_Modele_de_plan_de_classement.docx |
| C | Annexe_C_Registre_de_suivi_documentaire.xlsx | Annexe_C_Registre_de_suivi_documentaire.docx |
| D | Annexe_D_Fiche_de_pret_et_de_consultation.xlsx | Annexe_D_Fiche_de_pret_et_de_consultation.docx |
| E | Annexe_E_Tableau_de_gestion_et_de_conservation.xlsx | Annexe_E_Tableau_de_gestion_et_de_conservation.docx |
| F | Annexe_F_Bordereau_de_versement.xlsx | Annexe_F_Bordereau_de_versement.docx |
| G | Annexe_G_Proces_verbal_de_destruction.xlsx | Annexe_G_Proces_verbal_de_destruction.docx |
| H | Annexe_H_Fiche_de_diagnostic_archivistique.xlsx | Annexe_H_Fiche_de_diagnostic_archivistique.docx |
| I | Annexe_I_Modele_de_politique_d_archivage.xlsx | Annexe_I_Modele_de_politique_d_archivage.docx |
| J | Annexe_J_Checklist_de_controle_interne_des_archives.xlsx | Annexe_J_Checklist_de_controle_interne_des_archives.docx |

Chaque classeur Excel contient : un onglet **Mode d'emploi**, le **modèle** vierge (listes déroulantes, calculs et alertes automatiques, mise en page A4 prête à imprimer), un onglet **Exemple Horizon** rempli avec le cas fictif de l'ouvrage, et un onglet **Listes** modifiable qui alimente les menus déroulants.

Code couleur : bleu pastel = saisie ; jaune moutarde clair = calcul automatique (ne pas écraser) ; orange ou bordeaux = alerte.

Les durées de conservation des exemples sont fictives : appliquez votre tableau de gestion validé selon la législation de votre pays.
