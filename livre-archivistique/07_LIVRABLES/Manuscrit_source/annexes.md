## Annexe I · Modèle de politique d'archivage

::: modele
**POLITIQUE D'ARCHIVAGE DE [NOM DE L'ORGANISATION]** · Version ……… · Approuvée par ……… le ………

**1. Objet.** La présente politique fixe les principes et les règles de gestion des documents produits et reçus par [l'organisation], afin de garantir leur valeur de preuve, leur sécurité, leur accessibilité et le respect des obligations légales et contractuelles.

**2. Champ d'application.** Elle s'applique à tous les documents, quels que soient leur forme et leur support, à tous les services, sites, salariés, bénévoles et prestataires.

**3. Principes.** Respect des fonds ; gestion dès la création ; documents de l'organisation conservés exclusivement sur ses supports et espaces ; conservation selon le tableau de gestion ; aucune destruction hors procédure ; protection des données personnelles ; traçabilité.

**4. Rôles.** Direction ; responsable des archives ; chefs de service ; correspondants ; collaborateurs ; informatique (voir chapitre 10).

**5. Référentiels.** Plan de classement ; tableau de gestion ; grille de classification ; convention de nommage ; matrice des accès.

**6. Règles opérationnelles.** Enregistrement du courrier ; constitution des dossiers ; versements annuels ; prêts et consultations ; élimination avec PV ; suspension en cas de litige, audit ou enquête ; numérisation ; sauvegardes.

**7. Usage de l'intelligence artificielle.** Outils autorisés ; données interdites ; validation humaine selon l'enjeu.

**8. Contrôle et révision.** Indicateurs trimestriels ; récolement annuel par sondage ; revue annuelle de la politique.

**9. Entrée en vigueur.** La politique entre en vigueur le ……… et s'impose à tous.
:::

## Annexe J · Checklist de contrôle interne des archives

::: modele
| N° | Point de contrôle | Oui | Non | Preuve / observation |
|---|---|---|---|---|
| 1 | Une politique d'archivage approuvée existe et a été revue depuis moins d'un an. | ☐ | ☐ | |
| 2 | Un responsable des archives et des correspondants sont formellement désignés. | ☐ | ☐ | |
| 3 | Le plan de classement est appliqué au papier et au numérique. | ☐ | ☐ | |
| 4 | Le tableau de gestion est validé et chaque durée a un fondement écrit. | ☐ | ☐ | |
| 5 | Tout courrier entrant est enregistré au registre d'arrivée. | ☐ | ☐ | |
| 6 | Les prêts sont tracés ; aucun prêt en retard de plus de 30 jours. | ☐ | ☐ | |
| 7 | Le local est fermé, l'accès limité, le climat relevé chaque semaine. | ☐ | ☐ | |
| 8 | Les documents sont classifiés ; les droits d'accès ont été revus depuis moins d'un an. | ☐ | ☐ | |
| 9 | Les accès des personnes parties ont été désactivés à leur départ. | ☐ | ☐ | |
| 10 | Chaque élimination fait l'objet d'un PV signé ; aucune suspension n'a été ignorée. | ☐ | ☐ | |
| 11 | Les sauvegardes respectent la règle 3-2-1 et une restauration a été testée. | ☐ | ☐ | |
| 12 | Aucun document de l'organisation n'est stocké sur un compte personnel. | ☐ | ☐ | |
| 13 | Un récolement par sondage a été réalisé dans l'année, les écarts traités. | ☐ | ☐ | |
| 14 | La piste d'audit d'un échantillon d'opérations est complète. | ☐ | ☐ | |
| 15 | Les incidents sont enregistrés, analysés et suivis d'actions correctives. | ☐ | ☐ | |

*Exemple d'utilisation :* à Horizon, la checklist est remplie chaque année par Jonas, puis revue par l'auditeur externe ; en 2026, 14 points sur 16 sont conformes, les points 9 et 12 font l'objet d'un plan d'action.
