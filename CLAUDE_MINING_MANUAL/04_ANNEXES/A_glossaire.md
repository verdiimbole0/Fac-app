## Annexe A. Glossaire de l'intelligence artificielle et du secteur minier

Les termes sont classés par ordre alphabétique. Le chapitre de référence est indiqué entre parenthèses. Certains termes anglais d'usage courant sont donnés en italique.

### A.1. Intelligence artificielle et Claude

| Terme | Définition |
|---|---|
| Agent (IA agentique) | Système d'IA capable d'enchaîner des actions (lire, exécuter du code, utiliser des outils) pour atteindre un objectif, avec une part d'autonomie (16, 36). |
| Anonymisation | Traitement rendant impossible la ré-identification d'une personne (37). |
| API | Interface de programmation permettant à une application d'appeler les modèles Claude (4, 9). |
| Apprentissage automatique (*machine learning*) | Branche de l'IA dans laquelle un modèle apprend des régularités à partir de données (2). |
| Apprentissage par l'exemple (*few-shot*) | Technique consistant à fournir quelques exemples du résultat attendu dans l'instruction (11). |
| Apprentissage profond (*deep learning*) | Apprentissage automatique fondé sur des réseaux de neurones à nombreuses couches (2). |
| Artefact (*artifact*) | Contenu autonome créé par Claude (document, présentation, tableau de bord, outil) modifiable et partageable (15). |
| Balises | Délimiteurs (par exemple `<document>…</document>`) utilisés pour structurer une instruction (10, 11). |
| Biais | Déformation systématique des résultats, souvent héritée des données (2, 39). |
| CADRE | Méthode pédagogique de l'ouvrage : Contexte, Action, Données, Règles, Exigences de sortie (10). Non officielle. |
| Chaînage (*prompt chaining*) | Découpage d'une tâche en instructions successives avec contrôles intermédiaires (11). |
| Claude | Famille de grands modèles de langage développée par Anthropic (4). |
| Claude Code | Outil agentique de développement et d'automatisation (16). |
| Compétence (*Skill*) | Dossier d'instructions, scripts et ressources que Claude charge à la demande pour une tâche spécialisée (16). |
| Confabulation | Terme du NIST désignant la production de contenus faux présentés avec assurance (5). |
| Connecteur | Lien entre Claude et une application ou une source de données externe (16). |
| Conversation incognito | Conversation non enregistrée dans l'historique ni utilisée par la mémoire (12). |
| Cowork | Fonctionnalité de Claude pour les tâches longues en plusieurs étapes, y compris planifiées (16). |
| Date limite des connaissances | Date jusqu'à laquelle les connaissances d'entraînement d'un modèle sont fiables (3). |
| Divulgation progressive | Mécanisme par lequel Claude ne charge que les compétences pertinentes (16). |
| Effort | Paramètre réglant la quantité de travail (réflexion, texte, outils) consacrée à une réponse : low, medium, high, xhigh, max (9). |
| Exécution de code | Capacité de Claude à écrire et exécuter des programmes pour calculer, analyser des fichiers ou créer des documents (3, 13). |
| Fenêtre de contexte | Quantité maximale de texte (en tokens) prise en compte en une fois (3). |
| Grand modèle de langage (LLM) | Modèle entraîné sur de grandes quantités de textes pour prédire la suite d'un texte (3). |
| Hallucination | Réponse fausse ou inventée présentée avec assurance (5). |
| Humain dans la boucle | Organisation où un humain cadre, vérifie et valide les résultats de l'IA (6). |
| IA générative | IA capable de produire de nouveaux contenus (texte, images, code) (2). |
| IA prédictive | IA produisant une prédiction, une classe ou une alerte à partir de données (2). |
| Inférence | Utilisation d'un modèle entraîné pour produire une réponse (2). |
| Injection de prompt | Insertion d'instructions malveillantes, directes ou cachées dans un contenu lu, pour détourner un modèle (38). |
| MCP (*Model Context Protocol*) | Standard ouvert pour connecter des applications d'IA à des systèmes externes (16). |
| Mémoire | Fonction permettant à Claude de retenir des éléments d'une conversation à l'autre (12). |
| Modèle multimodal | Modèle traitant plusieurs types de données (texte, images) (3). |
| Paramètres (poids) | Coefficients internes d'un modèle ajustés pendant l'entraînement (2). |
| Porte de validation | Point d'un workflow où un humain désigné vérifie un résultat avant de continuer (36). |
| Projet (*Project*) | Espace de travail regroupant instructions, connaissances et conversations (15). |
| Prompt (instruction) | Texte donné au modèle pour lui demander une tâche (10). |
| Pseudonymisation | Remplacement des identifiants par des codes, réversible avec une table conservée à part (37). |
| RAG | Génération augmentée par recherche : le modèle recherche les passages pertinents d'une base documentaire (15). |
| Recherche approfondie (*Research*) | Fonction de recherche en plusieurs étapes sur le Web et les outils connectés (14). |
| Réflexion adaptative | Mode dans lequel le modèle décide quand et combien réfléchir avant de répondre (9). |
| Réseau de neurones | Modèle mathématique composé d'unités de calcul organisées en couches (2). |
| Token | Fragment de texte, unité de traitement et de mesure des modèles (3). |
| Transformer | Architecture de réseau de neurones à l'origine des grands modèles de langage (2). |

### A.2. Secteur minier

| Terme | Définition |
|---|---|
| Analyse de défaillance (causes racines) | Méthode d'identification des causes d'une défaillance pour éviter sa répétition (22). |
| Blanc (QA/QC) | Échantillon sans minéralisation inséré pour détecter une contamination (18). |
| Cahier des charges (communautaire) | Accord formalisant les engagements de l'entreprise envers les communautés (25). |
| Carotte de sondage | Cylindre de roche extrait par un sondage carotté (17). |
| CCD (décantation à contre-courant) | Étape de séparation solide-liquide par décanteurs en série (21). |
| Consignation | Mise en sécurité des sources d'énergie avant une intervention (22). |
| Contrôle critique | Contrôle qui prévient un événement majeur ou en limite les conséquences (23). |
| Découverture (rapport de) | Rapport entre le stérile et le minerai extraits (19). |
| Devoir de diligence | Démarche d'identification, de prévention et d'atténuation des risques dans la chaîne d'approvisionnement (32). |
| EIES | Étude d'impact environnemental et social (24). |
| Facteurs modificateurs | Facteurs (exploitation, métallurgie, économie, juridique, environnement, social…) qui convertissent des ressources en réserves (18). |
| Fosse | Excavation d'une mine à ciel ouvert (19). |
| GISTM | Norme mondiale de l'industrie sur la gestion des résidus miniers (2020) (24). |
| GMAO | Gestion de la maintenance assistée par ordinateur (22). |
| Gradin | Palier horizontal d'une fosse (19, 20). |
| Hétérogénite | Minéral oxydé de cobalt caractéristique du Copperbelt (17). |
| ITIE (EITI) | Initiative pour la transparence dans les industries extractives (27, 32). |
| Lixiviation | Mise en solution des métaux par un réactif (acide sulfurique) (21). |
| Matériau de référence certifié (standard) | Échantillon de teneur connue servant à contrôler l'exactitude des analyses (18). |
| Merlon | Bourrelet de sécurité en bord de piste ou de rampe (20, 23). |
| Parc à résidus | Installation de stockage des résidus de traitement (24). |
| Personne compétente | Professionnel qualifié responsable des déclarations de ressources et réserves (6, 18). |
| Plan de tir | Document définissant la géométrie, le chargement et la séquence d'un tir (20). |
| Rampe | Piste inclinée de circulation dans la fosse (20). |
| Récupération (métallurgique) | Part du métal alimenté effectivement récupérée (21). |
| Redevance minière | Prélèvement dû à l'État sur la production ou les ventes, selon la législation (28). |
| Réserves (probables, prouvées) | Partie économiquement exploitable des ressources indiquées et mesurées (18). |
| Ressources (présumées, indiquées, mesurées) | Concentrations minérales classées selon la confiance géologique (18). |
| SX-EW | Extraction par solvant et électrolyse, procédé de production de cathodes (21). |
| Taux de fréquence | Nombre d'accidents avec arrêt rapporté aux heures travaillées (selon la définition de l'entreprise) (23). |
| Teneur | Concentration d'un métal dans le minerai (% ou g/t) (17, 18). |
| Teneur de coupure | Teneur minimale à partir de laquelle un matériau est considéré comme minerai (18). |
