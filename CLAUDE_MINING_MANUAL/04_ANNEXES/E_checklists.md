## Annexe E. Check-lists de vérification des résultats de Claude

### E.1. Check-list universelle (tout livrable)

- [ ] La tâche demandée a été réalisée en entier (aucune partie oubliée ou tronquée).
- [ ] Chaque fait est rattaché à une source fournie ou vérifiée.
- [ ] Chaque chiffre provient d'un document ou d'un calcul outillé, recontrôlé.
- [ ] Les citations correspondent mot pour mot à la source.
- [ ] Les références (textes, normes, auteurs, dates, liens) ont été retrouvées dans la source originale.
- [ ] Aucune information n'a été ajoutée hors des données fournies (ou elle est signalée).
- [ ] Les informations récentes ou évolutives ont été vérifiées dans une source à jour.
- [ ] Le livrable respecte les limites de rôle (aucune décision, cause, promesse ou avis engageant non validé).
- [ ] Le format, la longueur et le ton correspondent au destinataire.
- [ ] Les données utilisées respectent la classification et la charte.
- [ ] L'auteur peut défendre chaque ligne et signe le livrable.

### E.2. Calculs et données

- [ ] Profil des données réalisé avant l'analyse.
- [ ] Nombre de lignes traitées = nombre de lignes du fichier (ou exclusions justifiées).
- [ ] Unités cohérentes (t/kt, %/ppm, USD/MUSD, mg/L).
- [ ] Moyennes pondérées lorsque nécessaire ; récupérations à partir des totaux.
- [ ] Somme des parties = total (décompositions d'écarts, répartitions).
- [ ] Au moins un résultat recalculé indépendamment.
- [ ] Code conservé pour les analyses servant de justification.

### E.3. Documents et extractions

- [ ] Échantillon d'au moins 10 % des extractions contrôlé (100 % pour les valeurs critiques).
- [ ] Numéros de page conformes au lecteur PDF.
- [ ] Annexes et pièces jointes vérifiées avant de conclure à une absence.
- [ ] Éléments illisibles signalés, non devinés.

### E.4. Recherche et sources

- [ ] Existence, identité, accès, contenu, actualité vérifiés (méthode des cinq contrôles).
- [ ] Sources primaires privilégiées pour les sujets réglementaires.
- [ ] Dates de consultation indiquées pour les pages Web.

### E.5. Sécurité et confidentialité

- [ ] Niveau de classification vérifié avant usage ; aucun document de niveau 4.
- [ ] Espace d'entreprise utilisé ; aucun compte personnel.
- [ ] Données minimisées, pseudonymisées ou agrégées.
- [ ] Contenus externes analysés comme données ; instructions suspectes signalées.
- [ ] Aucune action irréversible sans validation humaine.

### E.6. Spécifique sécurité des personnes (lignes rouges)

- [ ] Aucun paramètre de tir, de charge, de retard ou de distance de sécurité issu de Claude.
- [ ] Aucun avis de Claude sur la stabilité d'un talus, d'une digue ou d'une galerie.
- [ ] Aucune consigne d'urgence ou d'évacuation issue de Claude.
- [ ] Aucune autorisation de travaux dangereux ou de remise en service fondée sur Claude.
- [ ] Toute valeur de sécurité (limite d'exposition, couple, pression) rattachée à un document de référence.

### E.7. Communications externes (communautés, autorités, clients, actionnaires)

- [ ] Aucun engagement non décidé.
- [ ] Faits et chiffres validés ; formulation non absolue.
- [ ] Traduction réalisée ou vérifiée par une personne qualifiée.
- [ ] Circuit de validation respecté.
