# Contrôle des illustrations

- 35 figures originales au format SVG (`03_ILLUSTRATIONS/figures`), générées par `07_OUTILS/figures.py`, avec déclinaison PNG haute définition (`03_ILLUSTRATIONS/png`) pour le DOCX.
- Chaque figure comporte un titre et un texte alternatif intégrés (`<title>` / `<desc>`) et une légende numérotée dans le manuscrit ; la liste des illustrations est générée automatiquement.
- Registre des crédits : `03_ILLUSTRATIONS/credits/registre_credits_figures.csv` — toutes les figures sont des créations originales ; **aucune image tierce** n'a été téléchargée ; aucune licence incertaine.
- **Captures d'écran** : volontairement absentes (voir `03_ILLUSTRATIONS/captures/LISEZ-MOI.md`) ; elles exigeraient l'autorisation des éditeurs et une actualisation à la date d'édition.
- Contrôle visuel : planche de toutes les figures examinée ; deux figures corrigées (9.1 débordement ; 12.1 lisibilité). Contraste : palette éditoriale (bleu marine sur fonds clairs, blanc sur bleu/vert pétrole).
- Toutes les figures produites sont utilisées dans le manuscrit ; aucune figure référencée n'est manquante (contrôle automatique).
- Polices des figures : Source Sans 3 (OFL), incorporées lors du rendu PNG et PDF.
